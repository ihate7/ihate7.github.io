WinBackup

Резервное копирование файлов и баз данных для Windows-серверов.

WinBackup — это служба Windows, которая по расписанию сохраняет копии файлов и баз данных, и окно программы для её настройки. Программа устанавливается на собственный сервер организации и работает на нём.

Возможности

  • копирование папок и файлов, выгрузка баз 1С (BAF), Microsoft SQL Server и PostgreSQL;
  • архивы 7-Zip и ZIP с шифрованием AES-256;
  • сохранение копий сразу в несколько мест: локальные и внешние диски, сетевые папки (SMB), SFTP, FTP/FTPS, WebDAV, хранилища S3 и Google Диск;
  • хранение заданного числа последних копий, восстановление из архива, перенос копий между хранилищами;
  • уведомления о результатах по почте и в Telegram;
  • пользователи с правами по каталогам, доступ к окну программы по сети только через HTTPS.

Google Диск

Если в WinBackup выбрать Google Диск местом хранения копий, программа попросит доступ к Диску через окно входа Google. По умолчанию — только к файлам и папкам, которые создаёт сама программа (drive.file): остальное содержимое Диска ей не видно.

Доступ используется только для резервного копирования: программа создаёт папку для копий, загружает в неё архивы, показывает их список, удаляет устаревшие копии по заданному правилу хранения и скачивает копию для восстановления. Данные идут напрямую между сервером организации и Google — разработчик их не получает. Подробно — в политике конфиденциальности.

Кто пользуется

WinBackup не распространяется публично: программу устанавливает администратор на сервер своей организации. Вопросы о работе программы — этому администратору.

WinBackup

File and database backup for Windows servers.

WinBackup is a Windows service that backs up files and databases on a schedule, plus a desktop window to configure it. It is installed on and runs on the organization's own server.

Features

  • backup of folders and files, dumps of 1C (BAF), Microsoft SQL Server and PostgreSQL databases;
  • 7-Zip and ZIP archives with AES-256 encryption;
  • copies saved to several destinations at once: local and external disks, network shares (SMB), SFTP, FTP/FTPS, WebDAV, S3-compatible storage and Google Drive;
  • keeping a set number of recent copies, restore from an archive, moving copies between storages;
  • result notifications by email and Telegram;
  • users with per-folder permissions; network access to the window only over HTTPS.

Google Drive

When Google Drive is chosen as a backup destination, WinBackup asks for access to the Drive through the Google sign-in window. By default it requests access only to the files and folders the app itself creates (drive.file); the rest of the Drive is not visible to it.

The access is used for backups only: the app creates a folder for copies, uploads archives into it, lists them, deletes outdated copies according to the configured retention rule and downloads a copy for restore. Data travels directly between the organization's server and Google; the developer does not receive it. See the privacy policy for details.

Who uses it

WinBackup is not distributed publicly: an administrator installs it on their organization's server. Questions about the app should go to that administrator.

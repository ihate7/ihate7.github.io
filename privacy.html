Политика конфиденциальности WinBackup

Действует с 23 ноября 2026 г.

WinBackup — программа резервного копирования, которую администратор устанавливает на собственный сервер организации. Эта политика описывает, как программа работает с данными аккаунта Google, когда в ней подключён Google Диск.

Какие данные Google получает программа

  • Доступ к Google Диску через Google API. По умолчанию — область https://www.googleapis.com/auth/drive.file: программа видит только файлы и папки, которые создала сама. Если администратор сам выберет в настройках ресурса доступ ко всему Диску (https://www.googleapis.com/auth/drive), программа получит доступ ко всем файлам Диска, но использует его только так, как описано ниже.
  • Адрес электронной почты и имя аккаунта, сведения о занятом и свободном месте на Диске — чтобы показать в окне программы, к какому Диску она подключена.

Как программа использует эти данные

Только для резервного копирования по настройкам пользователя: создать папку для копий, загрузить в неё архивы и файлы копий, получить их список, удалить устаревшие копии по правилу хранения, скачать копию для восстановления или переноса в другое хранилище. Других действий с Диском программа не выполняет.

Где хранятся данные

  • Разрешение на доступ (ключ OAuth, refresh token) хранится только на сервере, где установлена программа, в зашифрованном виде (AES-256-GCM; ключ шифрования защищён средствами Windows).
  • Содержимое копий хранится на Google Диске пользователя. Архивы можно зашифровать паролем — тогда их содержимое недоступно без пароля.
  • Журналы работы программы (имена файлов и папок копий, результаты запусков) хранятся на том же сервере.

Передача данных

Данные передаются только напрямую между сервером пользователя и Google по защищённому соединению (HTTPS). Разработчик WinBackup не получает данных пользователей: у программы нет собственного сервера, она не отправляет статистику, не показывает рекламу и не передаёт данные третьим лицам. Данные, полученные от Google, не используются для рекламы и для обучения моделей искусственного интеллекта.

Уведомления о результатах заданий программа отправляет только туда, куда их настроил сам администратор (почта, Telegram). Они содержат название задания и итог запуска, но не содержимое копий.

Соблюдение правил Google

Использование и передача WinBackup информации, полученной через Google API, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ и удалить данные

  • Отозвать доступ можно в любой момент: Аккаунт Google → Безопасность → «Сторонние приложения и сервисы» (myaccount.google.com/connections). После этого программа больше не может обращаться к Диску.
  • При удалении ресурса «Google Диск» в программе сохранённый ключ доступа удаляется с сервера.
  • Копии на Google Диске — это файлы пользователя: их можно удалить на Диске как обычные файлы.

WinBackup Privacy Policy

Effective November 23, 2026.

WinBackup is a backup application that an administrator installs on their organization's own server. This policy describes how the app handles Google account data when Google Drive is connected to it.

Google data the app accesses

  • Access to Google Drive through Google APIs. By default the scope https://www.googleapis.com/auth/drive.file: the app sees only the files and folders it created. If the administrator chooses full Drive access in the resource settings (https://www.googleapis.com/auth/drive), the app gets access to all Drive files but uses it only as described below.
  • The account email address and name, Drive used and free space — to show in the app window which Drive it is connected to.

How the app uses this data

Only for backups configured by the user: create a folder for copies, upload backup archives and files into it, list them, delete outdated copies according to the retention rule, and download a copy to restore it or move it to another storage. The app performs no other actions on the Drive.

Where data is stored

  • The access grant (OAuth refresh token) is stored only on the server where the app is installed, encrypted (AES-256-GCM; the encryption key is protected by Windows).
  • Backup contents are stored on the user's Google Drive. Archives can be password-encrypted, making their contents unreadable without the password.
  • The app's logs (names of backup files and folders, run results) are stored on the same server.

Data sharing

Data travels only directly between the user's server and Google over a secure connection (HTTPS). The developer of WinBackup does not receive user data: the app has no server of its own, sends no statistics, shows no ads and does not share data with third parties. Data received from Google is not used for advertising or for training artificial intelligence models.

Job result notifications are sent only where the administrator configured them (email, Telegram). They contain the job name and the run result, not the backup contents.

Compliance with Google policies

WinBackup's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • Access can be revoked at any time: Google Account → Security → "Third-party apps & services" (myaccount.google.com/connections). After that the app can no longer access the Drive.
  • Deleting the Google Drive resource in the app removes the stored access grant from the server.
  • Backups on Google Drive are the user's own files and can be deleted on the Drive like any other files.
